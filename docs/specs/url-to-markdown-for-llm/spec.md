# URL → Markdown → LLM 전달 서비스

## 사용자에게 보이는 결과

사용자가 웹 페이지 URL을 붙여넣으면, 본문이 정제된 Markdown으로 변환되어 제목·저자와 함께 화면에 표시된다. 사용자는 이 결과를 복사하거나 `.md` 파일로 내려받을 수 있고, 선택적으로 프롬프트를 앞에 붙여 ChatGPT 또는 Claude의 새 대화로 바로 넘길 수 있다. 다크모드를 토글해 화면을 전환할 수 있다.

## 범위

- URL 입력 → 본문 Markdown 추출 → 결과 확인(제목/저자 헤더 + 렌더링된 Markdown) → 내보내기(복사/다운로드/ChatGPT·Claude로 전달)로 이어지는 단일 화면 흐름.
- 추출에는 defuddle 라이브러리를 사용한다(https://defuddle.md/docs). 입력 페이지의 본문·제목·저자 메타데이터 추출을 defuddle의 책임으로 둔다.
- 프롬프트 프리셋(요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘) 및 1회성 직접 입력.
- 다크모드 토글.

## 사용자 흐름과 수용 기준

### 1. 입력
- 사용자는 URL을 입력창에 붙여넣는다.
- 지우기 버튼을 누르면 입력값과 그 이후 모든 결과(변환 결과, 선택한 프롬프트 상태 포함)가 초기 입력 화면으로 리셋된다.
- 유효한 형식의 URL이 아니면 변환을 시작하지 않고 입력창 주변에 오류를 표시한다.

### 2. 변환
- 변환 시작 시 로딩 상태를 표시한다.
- 변환이 성공하면 결과 확인 화면으로 전환된다.
- 변환이 실패하면(페이지에 접근할 수 없음, 본문을 추출할 수 없음, 시간 초과 등) 입력 화면에 머무른 채 실패 사유를 사람이 이해할 수 있는 문구로 보여주고, 같은 URL로 다시 시도하거나 URL을 수정할 수 있다.

### 3. 결과 확인
- 결과 화면 상단에 defuddle이 추출한 페이지 제목을 헤더로 표시한다. 저자 정보가 있으면 제목 아래에 함께 표시하고, 없으면 저자 영역을 표시하지 않는다.
- 본문은 렌더링된 Markdown(서식이 적용된 형태)으로 보여준다.

### 4. 내보내기
- **복사하기**: 변환된 Markdown 원문(프롬프트 미포함)을 클립보드에 복사하고, 복사되었음을 알리는 피드백을 보여준다.
- **.md 파일 다운로드**: 변환된 Markdown 원문을 `.md` 파일로 내려받는다.
- **ChatGPT로 열기 / Claude로 열기**: 프롬프트가 선택되어 있으면 "프롬프트 + 변환된 Markdown"을, 선택되어 있지 않으면 "변환된 Markdown"만을 클립보드에 복사한 뒤, 해당 서비스의 새 대화 페이지를 새 탭으로 연다. 자동 전송이나 입력창 자동 채움에 의존하지 않으며, 사용자가 새 탭에서 직접 붙여넣는 것을 전제로 한다.

### 프롬프트
- 프리셋 3종(요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘) 중 하나를 선택하거나, "직접 입력"을 선택해 텍스트를 입력할 수 있다.
- 기본값은 "프롬프트 없음"이며, 이 상태에서 ChatGPT·Claude로 열기를 실행하면 프롬프트 없이 본문만 전달된다.
- 직접 입력한 프롬프트는 저장되지 않으며, 세션(현재 결과 화면)을 벗어나면 사라진다.

### 다크모드
- 화면 어디서나 접근 가능한 토글로 라이트/다크 모드를 전환할 수 있다.
- 상태 전환은 즉시 반영된다.

## 결정 사항과 근거

- **ChatGPT·Claude로 열기는 클립보드 복사 + 새 탭 열기로 구현한다.** 두 서비스 모두 URL 쿼리 파라미터(`?q=`)로 입력창을 채우는 방식이 커뮤니티에 알려져 있지만, 공식적으로 문서화되지 않았고 2025년 기준으로도 보안 정책 변경이나 배포로 인해 여러 차례 동작이 깨진 사례가 보고되었다(ChatGPT 측 자동 제출 차단, Claude 측 파라미터 제출 중단 버그 등). 본문 길이가 길면 URL 길이 제한에도 걸린다. 클립보드 복사 방식은 이런 외부 서비스의 비공식 동작 변경에 영향받지 않고 항상 동작한다. (사용자 확인됨)
- **본문 추출은 defuddle 라이브러리를 사용한다.** 사용자 요구사항으로 명시됨. defuddle은 `Document` 객체를 입력받아 `title`, `author`, Markdown 본문 등을 반환하는 라이브러리로, 최근까지 유지보수되고 있음을 확인했다(npm 최신 버전 0.19.6, 2026-10-24 배포).
- UI 구성은 기존 결정 계약 [ui-composition](../../decisions/ui-composition.md)을 따른다. 이 계약은 shadcn/ui 기반 공통 컴포넌트·시맨틱 토큰·상태(loading/empty/error/success) 설계 원칙을 규정하므로, 이 스펙은 화면별 예외를 추가하지 않는다.

## 가정 (저위험, 번복 가능)

- 변환 실패 메시지는 원인별로 세분화하되(접근 불가/추출 실패/시간 초과 등 범주 수준), 기술적 에러 코드를 그대로 노출하지 않는다.
- URL 유효성 검사는 변환 버튼 클릭(또는 제출) 시점에 수행한다.
- 결과 화면에서 제목이 없는 페이지는 URL 호스트명 등으로 대체 표시한다.
- 다운로드 파일명은 페이지 제목 기반으로 생성하고, 제목이 없으면 일반적인 기본 파일명을 사용한다.
- 다크모드는 시스템 설정을 기본값으로 따르되 토글로 즉시 덮어쓸 수 있고, 선택한 값은 다음 방문에도 유지된다.
- 전체 UI 문구는 한국어로 제공한다(스펙 작성 언어 및 프로젝트 대화 언어와 일치).

## 범위 밖 (이유)

- 로그인이 필요한 페이지, 크롤링을 차단하는 사이트, `localhost`/사설 네트워크 주소는 변환 대상에서 제외한다. 본문 추출이 서버 측에서 해당 URL에 접근 가능해야 가능한데, 이런 주소는 외부 서버가 접근할 수 없거나 접근이 허용되지 않기 때문이다. 이런 경우는 "변환 실패"로 처리된다.
- 변환 결과의 영구 저장(계정, 히스토리, 공유 링크)은 이 스펙에 포함하지 않는다. 요구사항에 저장 관련 언급이 없고, 직접 입력 프롬프트도 명시적으로 "저장하지 않음"으로 요구되었다.
- ChatGPT·Claude 외 다른 LLM 서비스로의 내보내기는 포함하지 않는다.

## 보류된 결정

- 없음 — 구현에 필요한 결정은 모두 확정하거나 저위험 가정으로 남겼다.

## 남은 위험

- defuddle의 Node 환경 사용(`defuddle/node`)은 호출 측 패키지의 ESM 설정(`"type": "module"`)을 요구한다고 공식 문서에 안내되어 있다. 이 프로젝트(Next.js 16 + Turbopack)의 번들링 환경에서 실제로 제약 없이 동작하는지는 구현 단계에서 확인이 필요하다.
- 일부 사이트는 서버 측 요청을 차단(봇 탐지, Cloudflare 등)하거나 응답이 과도하게 커서 변환이 느려지거나 실패할 수 있다. 어떤 경우를 "실패"로 분류하고 사용자에게 어떤 문구를 보여줄지는 구현 중 실제 사례를 보며 다듬어야 한다.
- 클립보드 쓰기 권한은 브라우저/보안 컨텍스트(HTTPS)에 따라 제한될 수 있다. 실패 시 사용자에게 수동 복사를 안내하는 대체 경로가 필요할 수 있다.
