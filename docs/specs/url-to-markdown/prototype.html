웹 페이지를 Markdown으로

URL을 붙여넣으면 본문만 뽑아 Markdown으로 바꿔 드려요. 그대로 복사하거나 ChatGPT·Claude로 가져가세요.

http:// 또는 https://로 시작하는 웹 페이지 주소를 넣어 주세요.

변환 결과가 여기에 보여요

블로그 글, 뉴스 기사, 문서 페이지처럼 본문이 있는 주소가 잘 바뀌어요.

가져올 수 없는 주소예요

localhost나 사설망 IP 주소는 변환하지 않아요. 인터넷에 공개된 페이지 주소를 넣어 주세요.

페이지를 가져오지 못했어요

사이트가 접근을 막았어요(403). 이 사이트는 자동으로 가져온 요청을 받지 않아요. 다른 주소로 다시 시도해 주세요.

본문을 찾지 못했어요

이 주소는 웹 페이지가 아니라 PDF 파일이에요. 글이 있는 웹 페이지 주소를 넣어 주세요.
