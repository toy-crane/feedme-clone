# URL을 Markdown으로 변환해 LLM으로 넘기기

웹 페이지 URL을 붙여 넣으면 본문만 Markdown으로 뽑아 보여 주고, 그 결과를 복사·다운로드하거나 ChatGPT·Claude에서 바로 이어 쓸 수 있게 합니다.

- 화면 구성: [prototype.html](./prototype.html) — 한 화면의 배치, 상태별 모습(비어 있음, 변환 중, 결과, 긴 글 결과, 가져오기 실패, 본문 없음, 잘못된 URL), 문구와 상호작용의 기준입니다.
- UI 구성 원칙: [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) — shadcn 컴포넌트와 semantic token 사용 기준입니다.
- 의존성 버전 정책: [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md) — defuddle 등 새 의존성을 추가할 때의 버전 기준입니다.

## 사용자가 얻는 것

- 읽고 싶은 웹 페이지의 광고·메뉴·댓글을 걷어 낸 본문을 Markdown으로 얻습니다.
- 그 Markdown을 한 번의 클릭으로 복사하거나 `.md` 파일로 받습니다.
- 원하는 지시(요약, 번역, 쉬운 설명, 직접 쓴 지시)를 앞에 붙여 ChatGPT나 Claude 새 탭에서 바로 대화를 시작합니다.

## 범위

한 화면에서 아래 흐름을 모두 처리합니다.

1. **입력**: URL 입력칸과 "Markdown으로 변환" 버튼. 입력이 있으면 칸 안에 지우기 버튼이 보이고, 누르면 입력·결과·프롬프트 선택이 모두 처음 상태로 돌아갑니다.
2. **변환**: 서버가 해당 URL의 HTML을 가져와 defuddle로 본문을 Markdown으로 추출합니다. 변환 중에는 결과 자리에 로딩 상태를 보여 줍니다.
3. **결과 확인**: 페이지 제목, 그 아래 저자·사이트·단어 수, 그리고 렌더링된 Markdown 본문을 보여 줍니다.
4. **내보내기**
   - Markdown 복사, `.md` 파일 다운로드: 결과 헤더의 제목 오른쪽에 아이콘 버튼으로 둡니다.
   - 프롬프트 선택(선택 사항): 프리셋 "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘"와 "직접 입력". 한 번에 하나만 고를 수 있고, 고른 칩을 다시 누르면 선택이 풀립니다. "직접 입력"을 고르면 텍스트 입력칸이 나타납니다.
   - ChatGPT로 열기, Claude로 열기
   - 프롬프트 칩과 두 열기 버튼은 결과 카드 아래쪽의 고정 바에 모읍니다. 본문을 스크롤하는 동안에도 화면 아래에 계속 보입니다.
5. **다크 모드 토글**: 헤더의 버튼으로 밝은 테마와 어두운 테마를 바꿉니다.

## 수용 기준

- 사용자가 `http://` 또는 `https://` 웹 페이지 URL을 넣고 변환하면, 해당 페이지의 제목과 본문이 렌더링된 Markdown으로 표시된다.
- 결과 헤더에 제목이 표시되고, 저자·사이트·단어 수 중 값이 있는 것만 표시된다. 저자가 비어 있으면 저자 자리를 아예 그리지 않는다.
- 변환이 진행되는 동안 로딩 상태가 보이고, 변환 버튼을 다시 눌러 중복 요청을 만들 수 없다.
- `http(s)` URL 형식이 아닌 입력으로 변환하면 요청을 보내지 않고 입력칸 아래에 형식 오류 문구가 보인다.
- 대상 사이트가 오류 응답(예: 403, 404)을 주거나 접속할 수 없으면 "페이지를 가져오지 못했습니다" 오류가 사유와 함께 보인다. 오류 페이지의 내용을 결과처럼 보여 주지 않는다.
- 페이지는 가져왔지만 추출된 본문이 비어 있으면 "본문을 찾지 못했습니다" 오류가 보인다.
- 지우기 버튼을 누르면 입력칸이 비고, 결과·오류·프롬프트 선택과 직접 입력 내용이 모두 사라져 첫 화면 상태가 된다.
- "Markdown 복사"를 누르면 내보내기 텍스트가 클립보드에 들어가고 복사됐다는 알림이 보인다.
- ".md 다운로드"를 누르면 내보내기 텍스트를 담은 `.md` 파일이 내려받아지고, 파일 이름은 페이지 제목에서 만든다.
- 프롬프트를 고르지 않고 ChatGPT·Claude로 열면 내보내기 텍스트만 전달된다. 프롬프트를 고르면 프롬프트가 내보내기 텍스트 앞에 붙어 전달된다. "직접 입력"을 골랐지만 칸이 비어 있으면 프롬프트 없이 전달된다.
- 전달할 전체 텍스트(프롬프트 포함)로 만든 열기 주소가 기준 길이 이하이면, 새 탭에서 ChatGPT(`https://chatgpt.com/?q=…`) 또는 Claude(`https://claude.ai/new?q=…`)가 열리고 입력창에 그 텍스트가 채워진다.
- 기준 길이를 넘으면 전체 텍스트를 클립보드에 복사한 뒤 새 탭에서 빈 대화를 열고, "글이 길어 클립보드에 복사했으니 붙여 넣어 달라"는 안내를 보여 준다. 어느 경우에도 본문이 잘린 채 전달되지 않는다.
- 직접 입력한 프롬프트는 저장되지 않는다. 지우기, 다른 URL 변환, 새로고침 후에는 남아 있지 않다.
- 다크 모드 토글을 누르면 화면 전체가 어두운 테마로 바뀌고, 다시 누르면 밝은 테마로 돌아온다. 렌더링된 Markdown(코드 블록, 인용, 링크 포함)도 두 테마에서 모두 읽을 수 있다.
- 긴 본문을 어디까지 스크롤했든 프롬프트 칩과 ChatGPT·Claude 열기 버튼이 화면 아래에 보이고, 위로 되돌아가지 않고 바로 누를 수 있다. 복사·다운로드 버튼은 제목 옆에 있다.
- 좁은 화면(390px 폭)에서도 입력, 결과, 내보내기 버튼이 가로 스크롤 없이 모두 보이고 쓸 수 있다.

## 정해진 제약과 이유

- **본문 추출은 defuddle로 한다.** 사용자가 지정한 필수 라이브러리입니다. 스크래치 환경에서 defuddle 0.19.6 + linkedom으로 확인했고, `defuddle/node`의 `Defuddle(document, url, { markdown: true })`가 `title`, `author`, `site`, `wordCount`, Markdown 본문(`content`)을 돌려줍니다. 문서: https://defuddle.md/docs
- **변환은 서버에서 한다.** 브라우저에서는 CORS 때문에 다른 사이트의 HTML을 직접 가져올 수 없습니다.
- **LLM으로 넘길 때는 "짧으면 주소, 길면 클립보드"로 한다.** 사용자가 확정했습니다. 긴 글(예: 6만 자가 넘는 에세이)을 주소에 모두 담으면 잘리거나 열리지 않을 수 있고, 항상 클립보드를 쓰면 짧은 글에서도 매번 붙여 넣어야 하기 때문입니다.
- **LLM 보내기 영역은 하단 고정 바에 둔다.** 본문 위 패널, 하단 고정 바, 오른쪽 사이드 패널 세 안을 비교해 확정했습니다. 본문 위 패널은 읽으며 내려가면 버튼이 사라지고, 사이드 패널은 좁은 화면에서 제목을 밀어 내립니다. 하단 바는 휴대폰에서 본문을 일부 가리지만, 읽던 자리에서 바로 보낼 수 있다는 점을 우선했습니다.
- **오류 응답을 결과로 보여 주지 않는다.** 확인해 보니 defuddle은 차단된 페이지(nytimes, HTTP 403)에서도 "Please enable JS and disable any ad blocker" 같은 내용을 본문으로 돌려줍니다. 대상 사이트의 응답 상태를 보고 실패로 처리해야 합니다.

## 가정 (바꿔도 되는 기본값)

- 서비스 이름은 저장소 이름을 따라 "feedme"로 둡니다.
- 내보내기 텍스트는 복사·다운로드·LLM 전달에 모두 같은 것을 씁니다. 맨 위에 `# 제목`, 다음 줄에 출처 URL(저자가 있으면 저자도), 빈 줄, 그다음 Markdown 본문입니다.
- 프롬프트는 LLM 전달에만 붙습니다. 복사와 다운로드에는 붙지 않습니다.
- 프롬프트를 붙일 때는 `프롬프트` + 빈 줄 + 내보내기 텍스트 형태로 합칩니다.
- "기준 길이"는 완성된 열기 주소(인코딩 후) 8,000자로 둡니다.
- 다크 모드는 처음에 시스템 설정을 따르고, 사용자가 토글로 고른 값은 같은 브라우저에서 다시 열 때 유지합니다.
- `.md` 파일 이름은 제목을 파일명에 쓸 수 있게 다듬어 만들고, 제목이 없으면 도메인 이름을 씁니다.
- 결과는 렌더링된 Markdown만 보여 줍니다. 원문 Markdown 보기 전환은 두지 않습니다.
- 프롬프트 선택은 새 URL을 변환하면 초기화됩니다.

## 범위 밖

- 변환 기록, 계정, 저장 기능: 요청에 없고, 직접 입력 프롬프트도 1회용으로 정했습니다.
- 로그인이 필요하거나 자바스크립트로만 내용을 그리는 페이지의 추출: defuddle은 받아 온 HTML만 다루며, 헤드리스 브라우저 렌더링은 범위 밖입니다.
- ChatGPT·Claude API를 직접 호출해 답을 받아 오는 기능: 이 서비스는 대화를 시작할 곳으로 넘겨 주기만 합니다.
- 스펙이 요구하지 않은 보안 하드닝(요청 속도 제한, 내부망 주소 차단 등): 강의용 템플릿의 검증 예산(AGENTS.md)에 따라 다루지 않습니다.

## 남은 위험

- **주소로 미리 채우기 동작은 확인하지 못했습니다.** `chatgpt.com/?q=`와 `claude.ai/new?q=`가 입력창을 채우는지, 자동으로 전송까지 하는지, 몇 자까지 받는지는 로그인한 브라우저에서만 확인할 수 있어 셰이핑 중에 검증하지 않았습니다. claude.ai는 스크립트 요청을 403으로 막습니다. 구현할 때 실제 브라우저로 확인하고, 8,000자 기준이 맞지 않으면 기준 길이만 조정합니다. 두 서비스가 이 주소 형식을 없애면 클립보드 방식만 남게 됩니다.
- **새 탭 열기와 클립보드 복사가 함께 동작해야 합니다.** 긴 글에서 클립보드 복사 후 새 탭을 열 때 브라우저의 팝업 차단에 걸리지 않는지 확인이 필요합니다.
- **사이트마다 추출 품질이 다릅니다.** 저자 값이 비는 경우가 흔하고(Paul Graham 에세이), 봇을 막는 사이트는 실패합니다. 이 경우는 오류로 안내하는 것이 기대 동작입니다.
